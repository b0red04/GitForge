# Icon attribution

UI icons in this directory are sourced from [Lucide](https://lucide.dev/) ([ISC License](https://github.com/lucide-icons/lucide/blob/main/LICENSE)).

`github.svg` and `gitlab.svg` are taken from Lucide v0.544.0 (the last release that included brand icons; Lucide v1+ removed brand logos per [their migration guide](https://lucide.dev/guide/packages/migration)).

To refresh icons from upstream:

```bash
./scripts/sync-lucide-icons.sh
```
