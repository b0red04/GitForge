# Keyboard Shortcuts Reference

## Global Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open Repository |
| `Ctrl+Shift+P` | Command Palette |
| `Ctrl+Shift+T` | Toggle Theme (Dark/Light) |
| `Escape` | Close Dialog / Dismiss |

## Navigation

| Shortcut | Action |
|---|---|
| `↑` | Select previous commit |
| `↓` | Select next commit |
| `Enter` | View file at commit |
| `Escape` | Back to diff |

## Git Operations

| Shortcut | Action |
|---|---|
| `Ctrl+N` | Create Branch |
| `Ctrl+Shift+S` | Stash Changes |
| `Ctrl+Shift+O` | Pop Stash |
| `Ctrl+Shift+F` | Fetch All |
| `Ctrl+Shift+U` | Pull |
| `Ctrl+Shift+H` | Push |

## Command Palette

The command palette (`Ctrl+Shift+P`) provides access to all actions with fuzzy search:

- Type to filter commands
- `↑/↓` to navigate
- `Enter` to execute
- `Escape` to dismiss
- `Ctrl+P` / `Ctrl+N` to navigate (alternative)
