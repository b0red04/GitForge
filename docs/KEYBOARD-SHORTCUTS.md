# Keyboard Shortcuts Reference

## Global Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open Repository |
| `Ctrl+Shift+P` | Command Palette |
| `Ctrl+Shift+T` | Cycle Theme |
| `Escape` | Close Dialog / Dismiss (settings window: close settings) |

## File Menu

| Shortcut | Action |
|---|---|
| `Ctrl+T` | New Tab |
| `Ctrl+W` | Close Tab |
| `Ctrl+I` | Init Repository |
| `Alt+Ctrl+O` | Open Settings (Repositories) |
| `Ctrl+Shift+E` | Open Repo in External Editor |
| `Alt+T` | Open External Terminal |
| `Alt+O` | Open in File Manager |
| `Ctrl+,` | Open Settings Window |
| `Ctrl+Q` | Quit GitForge |

Reopen Closed Tab and Clone Repository are available from the File menu without global shortcuts (to avoid conflicting with Create Branch and Cycle Theme).

## Navigation

| Shortcut | Action |
|---|---|
| `↑` | Select previous row in commit history (includes **Uncommitted Changes** when present) |
| `↓` | Select next row in commit history (includes **Uncommitted Changes** when present) |
| `Enter` | View file at commit |
| `Escape` | Back to diff |

## Git Operations

| Shortcut | Action |
|---|---|
| `Ctrl+N` | Create Branch |
| `Ctrl+Shift+S` | Stash Changes |
| `Ctrl+Shift+O` | Pop Stash |
| `Ctrl+Shift+F` | Fetch All |
| `Ctrl+Shift+U` | Pull |
| `Ctrl+Shift+H` | Push |

## Command Palette

The command palette (`Ctrl+Shift+P`) provides access to all actions with fuzzy search:

- Type to filter commands
- `↑/↓` to navigate
- `Enter` to execute
- `Escape` to dismiss
- `Ctrl+P` / `Ctrl+N` to navigate (alternative)
